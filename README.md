# 🛒 ZEVRIX — Digital Store

فروشگاه آنلاین محصولات دیجیتال (لایسنس نرم‌افزار، VPN، ابزار AI، اشتراک‌ها) با پنل مدیریت فارسی.

## ✨ امکانات

- 🏪 **فروشگاه** — کاتالوگ محصولات، دسته‌بندی‌ها، سبد خرید، تسویه حساب، جستجو، دو زبانه (فارسی/انگلیسی)
- 🔐 **پنل مدیریت** — داشبورد آمار، مدیریت محصولات + آپلود تصویر، مدیریت سفارش‌ها، تغییر رمز
- 🎬 **هیرو سینمایی A.R.I.A** — ویدیوی تمام‌صفحه با اسکراب موس (افقی + عمودی) و افکت parallax
- 💳 **پرداخت امن** — ثبت سفارش با ایمیل و کد پیگیری

## 🧱 تکنولوژی‌ها

| لایه | تکنولوژی |
|------|----------|
| Frontend | HTML + CSS + Vanilla JS (RTL) |
| Backend | Node.js + Express |
| Database | SQLite (`node:sqlite`) |
| Auth | JWT + bcrypt |

## 🚀 اجرای محلی

```bash
cd digital-store/server
npm install
npm run seed     # ساخت دیتابیس + ادمین + محصولات نمونه
npm start        # http://localhost:4100
```

**ورود پنل:** http://localhost:4100/admin → `admin` / `admin12345`

## 🌐 دیپلوی روی سرور (یک خط!)

روی یه VPS اوبونتو (۲۲.۰۴ یا ۲۴.۰۴) با دسترسی root:

```bash
bash deploy.sh yourdomain.com
```

این اسکریپت خودش این‌ها رو انجام می‌ده:
Node.js 22، Nginx، PM2، فایروال UFW، گواهی SSL رایگان Let's Encrypt، بکاپ روزانه دیتابیس، و راه‌اندازی خودکار سایت روی `https://yourdomain.com`.

> **پیش‌نیاز:** دامنه خریداری شده و رکورد `A` دامنه به IP سرور اشاره کنه.

## 📁 ساختار پروژه

```
digital-store/
├── index.html              # فروشگاه
├── css/  js/               # استایل و منطق فروشگاه

    ├── seed.js             # دیتابیس اولیه

    └── public/             # پنل مدیریت
```
