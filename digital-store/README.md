# 🚀 ZEVRIX — راه‌اندازی

## اجرای سرور (یک بار برای همیشه)

```bash
cd digital-store\server
npm install      # فقط دفعه اول
npm run seed     # فقط دفعه اول (ساخت دیتابیس + ادمین + محصولات)
npm start        # اجرای سرور
```

## آدرس‌ها

| بخش | آدرس |
|------|------|
| 🏪 **فروشگاه ZEVRIX** | http://localhost:4100 |
| 🔐 **پنل مدیریت** | http://localhost:4100/admin |

## ورود به پنل

```
نام کاربری: admin
رمز عبور:   admin12345
```

> رمز عبور رو از داخل پنل ← «تنظیمات» می‌تونی تغییر بدی.

## امکانات پنل

- **داشبورد**: آمار فروش، تعداد محصولات، سفارش‌های در انتظار، درآمد
- **محصولات**: افزودن / ویرایش / حذف محصول، آپلود تصویر، جستجو
- **سفارش‌ها**: مشاهده سفارش‌ها، تغییر وضعیت (در انتظار / پرداخت شده / تحویل شده / لغو شده)
- **تنظیمات**: تغییر رمز عبور مدیر

## تکنولوژی‌ها

- Frontend: HTML + CSS + JS خالص (بدون فریم‌ورک)
- Backend: Node.js + Express
- Database: SQLite (ماژول داخلی Node 24)
- Auth: JWT + bcrypt
